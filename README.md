# flutter workshop ui project

โปรเจค **flutter workshop ui project** เป็นโปรเจคสำหรับรายวิชา **Mobile Development** จัดทำขึ้นเพื่อฝึกการพัฒนา Mobile Application ด้วย **Flutter และ Dart**

ในส่วนที่รับผิดชอบปัจจุบันเป็นการพัฒนา **User Interface (UI)** ของแต่ละหน้าที่เกี่ยวข้องกับระบบ Login และการจัดการรหัสผ่าน โดย **ยังไม่ได้เชื่อมต่อกับระบบ Authentication หรือ Backend** เป็นเพียงส่วนของหน้าจอและ UI Flow เท่านั้น

## 📱 Pages / UI ที่พัฒนา

| UI | Description |
|---|---|
| `e01_page_ui.dart` | หน้า Home สำหรับแสดงหน้าหลักของแอปพลิเคชัน |
| `e02_page_ui.dart` | หน้า Login สำหรับแสดง UI การเข้าสู่ระบบ |
| `e03_page_ui.dart` | หน้า Register สำหรับสมัครสมาชิก |
| `e04_page_ui.dart` | หน้า Forgot Password สำหรับเริ่มต้นกระบวนการกู้คืนรหัสผ่าน |
| `e05_page_ui.dart` | หน้า OTP สำหรับแสดง UI การกรอกรหัสยืนยัน |
| `e06_page_ui.dart` | หน้าสำหรับกรอกรหัสผ่านใหม่ |

## 🛠️ Technologies

## 🎯 Project Objectives

โปรเจคนี้จัดทำขึ้นเพื่อ:

- เรียนรู้การพัฒนา Mobile Application ด้วย Flutter
- ฝึกเขียน UI ด้วย Flutter และ Dart
- ฝึกออกแบบหน้าจอสำหรับ Mobile Application
- ฝึกสร้าง Navigation ระหว่างหน้าต่าง ๆ
- ออกแบบ UI Flow สำหรับ Login และ Password Management
- เตรียม UI สำหรับนำไปเชื่อมต่อกับ Backend / Authentication ในขั้นตอนถัดไป
- ฝึกการทำงานร่วมกันและแบ่งส่วนงานภายในโปรเจค
